# 명일방주 2025년 오퍼레이터 보강

2025년 글로벌 공식 출시 공지 12건과 한국 서버 게임 데이터의 오퍼레이터 이름·능력치·스킬·재능·모듈을 대조했습니다. 신규 42명에 기존 12월 출시 2명(레이즈 더 썬더브링어, 레코드키퍼)을 더해 2025년 신규 오퍼레이터 44명을 수록합니다. 기존 오퍼레이터 파일과 이미지는 수정하지 않았습니다.

이벤트 보상·상점 교환·한정 및 콜라보 전용·1성 CONFESS-47까지 포함합니다. 출시 이력은 한국 공식 카페(업데이트·헤드헌팅 공지)와 대조해 한국 서버 시작 시각(KST)과 배너명으로 보강했습니다.

목록에서는 작은 초상화를, 상세 페이지에서는 게임 클라이언트의 정예화 전신 일러스트(1성은 기본 일러스트)를 사용합니다. 두 파일 모두 로컬 WebP이며 원본 리소스 URL을 각 레코드에 명시했습니다. 전신 일러스트는 키비주얼처럼 보여주되 이벤트 배너나 별도 공식 홍보 포스터와 혼동하지 않습니다.

스킬 문구는 한국 클라이언트 최종 레벨 값을 토대로 요약했습니다. 수치 출처는 [ArknightsGamedata 한국어 데이터](https://github.com/ArknightsAssets/ArknightsGamedata/tree/master/kr/gamedata/excel)이며, 초상화·전신 일러스트 원본은 기존 캐릭터와 동일한 게임 리소스 미러입니다. 특화 가치 계산(`analysis/<id>-mastery`)과 커뮤니티 평가(`community/<id>-evaluation`)를 41명에 추가했습니다. 평가는 Reddit Mastery Priority Guide 등급과 디시 명일방주 갤러리 출시 후 60일 글(직접 열람한 글만)을 요약했습니다. CONFESS-47은 근거 글이 부족해 평가·계산을 넣지 않았습니다. 특수 모드 모듈은 일반 모듈과 구분합니다.

검증: `tests/arknights-2025.test.ts`가 명단, 기존 캐릭터와의 중복, 공식/게임 데이터 출처, 이미지 84개의 존재·고유성 및 공통 스키마를 검사합니다.
