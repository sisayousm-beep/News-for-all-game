# 디자인 시스템 — Editorial Light

프리미엄 뉴스 미디어 + 게임 DB + 개인 허브. **정보가 장식보다 우선**한다.
구현: `src/styles/global.css` (토큰 → 셸 → 컴포넌트 순). 컴포넌트: `src/components/`, 모듈 화면: `src/modules/`.

## 원칙

1. **카드 대신 선과 타이포그래피.** 섹션은 굵은 검정 상단선(2px) + 제목으로 구분하고, 목록은 1px 구분선. 카드(흰 면 + 테두리)는 게임 카드처럼 독립된 대상에만 쓴다.
2. **중요한 것만 크게.** 한 화면에 큰 제목은 하나(Featured 첫 항목, 기사 제목). 나머지 메타데이터는 13px 회색.
3. **게임 색은 accent로만.** `--accent` 하나로 게임 표식(■), 탭 밑줄, 썸네일 틴트, 아이콘 배경을 바꾼다. 레이아웃·폰트·간격은 모든 게임이 같다.
4. **신뢰도와 정보 단계는 항상 보인다.** 공식 항목에는 신뢰 배지 1개. 정보 단계는 텍스트 배지 **공식(녹색) · 계산(보라) · 커뮤니티(황토)**로 표시하고, 항상 공식 → 계산 → 커뮤니티 순서로 배치한다([information-layers.md](information-layers.md)).
5. **모바일은 별도 설계.** 하단 탭, 썸네일 대체 타일 숨김, 3열 DB 그리드, 가로 스크롤 필터. 한 화면에 뉴스 제목 4~6개.

| 그룹 | 토큰 | 값 | 용도 |
|---|---|---|---|

| 선 | `--line` / `--line-strong` | `#e4e2dc` / `#cfccc4` | 목록 구분 / 입력·버튼 테두리 |
| 글자 | `--ink` / `--ink-2` / `--muted` / `--faint` | `#17191c` / `#3a3e44` / `#676b72` / `#979aa0` | 제목 / 본문 / 메타 / 비활성 |
| 강조 | `--brand` → `--accent`, `--accent-ink`, `--accent-tint` | `#17766a` 기본 | 게임 페이지에서는 `theme.accent`로 교체. 글자에는 어두운 `--accent-ink` |
| 신뢰 | `--official` `--press` `--db` `--reported` `--spec` `--ai` (+`-bg`) | 녹청·파랑·슬레이트·황토·적갈·보라 | 배지 글자색 + 옅은 배경 |
| 상태 | `--ongoing` `--upcoming` `--ended` | 녹청·파랑·회색 | 점 + 글자 |

게임 accent 예: 메이플 `#d9652f`(웜 코랄), 명조 `#3f6e8c`(슬레이트 블루). 새 게임은 흰 배경에서 3:1 이상 대비가 나는 중간 명도를 고른다.

### 타이포그래피 (Pretendard, 숫자는 tabular)

| 역할 | 클래스 | 데스크톱 / 모바일 |
|---|---|---|
| 페이지 제목 | `.page-title` | 26 / 22px, 750 |
| 기사·상세 제목 | `.article-title` | 30 / 22px, 800 |
| Featured 제목 | `.feature .headline` | 24(첫 항목)·20 / 17px |
| 섹션 제목 | `.section-title` | 17px, 700 |
| 목록 헤드라인 | `.headline` | 16 / 15px, 650 |
| 본문·리드 | `body`, `.article-lead` | 15px·17px, 행간 1.6–1.8 |
| 메타데이터 | `.meta` | 13px, `--muted` |
| 배지 | `.badge` | 11px, 700 |

### 간격·모양

- 간격: `--s1..s7` = 4, 8, 12, 16, 24, 32, 48px. 섹션 사이 32px(모바일 24), 목록 행 상하 12–14px.
- 모서리: `--r-sm` 3px(배지·칩), `--r` 6px(카드·썸네일, 모바일 4px). 알약(pill) 형태 없음.
- 그림자: 없음. 메뉴 등 떠 있는 요소만 `--shadow-pop`. blur·gradient 장식 없음(이미지 위 글자 가독성용 어두운 그라데이션만 허용).
- 이미지: 게임 식별·내용 전달용 공식 이미지만. 목록 썸네일 16:10, Featured 16:9, 이벤트 배너 2.375:1, 초상 3:4.
- 최대 폭 1280px, 좌우 24px(모바일 16px). 본문 그리드 8/4(`.layout`), 필요 시 7/5(`.layout-7-5`).

## 화면 구조

| 화면 | 데스크톱 | 모바일 |
|---|---|---|
| 홈 `/` | 제목 + 날짜 → Featured(게임별 최신 대형 소식, 1.35:1:1 비대칭) → 8/4: 최신 뉴스 │ 진행 중 이벤트 · 주요 일정 · 최근 DB 변경 → 게임 한눈에 보기 | 게임 바로가기 칩 → Featured(첫 항목만 요약) → 뉴스 → 이벤트 → 일정 → DB 변경 → 게임 카드 1열 |
| 뉴스 `/news/` | 8/4: 게임 칩 + 분류 필터 + 목록 + 페이지 이동 │ 다가오는 일정, 정보 표시 기준(범례) | 가로 스크롤 필터, 썸네일 없는 조밀한 목록 |
| 일정 `/schedule/` | 게임·종류 필터 → 오늘 / 진행 중 / 이번 주 / 이후 / 최근 종료 그룹(왼쪽 그룹 제목 고정) | 그룹 제목이 행 위로, 날짜 열 50px |
| 게임 허브 `/games/<id>/` | 아이콘·이름·장르·서비스사 + 핵심 수치(진행 중 이벤트, 다음 일정, DB 수) → 탭 → 8/4: 뉴스(대표 1 + 목록) │ 일정·DB 위젯 | 수치가 한 줄 아래로, 탭 상단 고정 |
| DB 목록 | 검색 + 필드 필터 + 개수 + 그리드/목록 전환 | 3열 그리드 |
| DB 상세 | 240px 좌측(초상, 이름, 별칭, 신뢰, 속성표, 단계 바로가기) │ [공식] 기본 정보 · 섹션별 토픽 · 변경 이력 → **한눈에 보기**(커뮤니티 판정 + 첫 계산 결론) → … → [계산] 성능 분석 → [커뮤니티] → 관련 뉴스 → 출처 | 초상 96px + 이름 가로 배치 → 속성표 → 본문 |
| 뉴스 상세 | 8/4: 게임·분류·신뢰 → 제목 → 게시·출처 수·갱신 → 리드 → 태그 → 출처·검증 → 연결된 계산·커뮤니티 │ 같은 게임 다른 소식 | 1열 |
| 일정 상세 | 상태·남은 기간·시작·종료 4칸 → 요약 → 출처 │ 다른 일정 | 4칸이 2×2 |

게임별 차이는 **모듈 구성(game.yaml)과 accent 색**뿐이다. 위젯 배치는 모듈 타입으로 정한다(news → 넓은 열, schedule·database → 좁은 열).

## 새 요소를 추가할 때

- 정보 탐색에 필요한가? 아니면 넣지 않는다(장식 아이콘, 의미 없는 그라데이션 금지).
- 새 색을 만들지 말고 토큰을 쓴다. 게임별 색은 `--accent`만.
- 같은 정보는 같은 컴포넌트로 표시한다(뉴스는 어디서나 `NewsItem`, 일정은 `EventItem`).
- 모바일(390px)에서 한 항목이 화면 1/4을 넘지 않는지 확인한다.
