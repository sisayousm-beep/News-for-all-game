# 엔드필드 모듈

2026-09-27 확인, Asia 서버·한국어, 1.5 버전 중심의 첫 데이터 묶음입니다.
전체 오퍼레이터 도감을 완성한 상태는 아닙니다.

## 기존 구현에서 재사용한 원칙

- 게임별 화면 분기 없이 `game.yaml`의 모듈·필드·섹션으로 화면을 구성합니다.
- 공식/계산/커뮤니티를 분리하고 `subjects`로 동일 오퍼레이터·이벤트에 연결합니다.
- 명조의 공명 체인을 그대로 복제하지 않고 잠재능력·직업·무기 종류를 엔드필드에 맞췄습니다.
- 엔드필드 고유의 공업·생산 항목을 별도 데이터베이스로 추가했습니다.
- 기존 게임, 공통 UI, 배포 설정은 수정하지 않습니다. 명일방주 병행 작업과 독립적입니다.

## 현재 범위

- 버전 1개, 오퍼레이터 3명, 무기 4종, 장비 세트 1개, 공업 항목 3개.
- 이벤트·픽업·점검 22건, 뉴스 5건, 계산 4건, 출처별 평가 1건.
- 공식 이미지 4개를 로컬 WebP로 제공하며 뉴스의 `imageFrom`에 원본을 기록했습니다.
- 최신 픽업·무료 배포의 티프로스/푸치나/이본을 우선했습니다. 이본의 최초 출시일은 추정하지 않습니다.
- 코드 모듈은 준비했으나 유효성이 확인된 코드가 없어 레코드를 만들지 않았습니다.

## 엔드필드에서 특별히 주의할 점

1. 공식 Asia 시간은 UTC+8입니다. 원문 오프셋을 저장하고 공통 UI가 한국 시간으로 표시하게 합니다.
2. 통합 지원의 생산·제출 마감과 교환소 마감을 별도 이벤트로 관리합니다.
3. 겨울 사냥 종료일은 버전 종료일이나 한기 신청 종료일이 아닙니다. 미발표 날짜는 `null`입니다.
4. 80회 6성 보장, 최초 픽업 120회 보장, 긴급 모집 제외 규칙을 혼합하지 않습니다.
5. 특별 허가와 재구축은 보상·이월 조건이 다릅니다. 다음 배너 티켓을 현재 배너 모집 횟수에 더하지 않습니다.
6. 캐릭터 공략의 스킬·잠재 수치는 `reported`입니다. 위키는 WIKI, 공략은 GUIDE로 등록합니다.
7. 티어는 출처와 콘텐츠 기준을 명시한 커뮤니티 평가입니다. 유저 전체의 합의로 표현하지 않습니다.

## 의도적으로 남긴 공백

- 과거 전체 캐릭터·무기·장비와 공업 레시피/생산량 도감.
- 관문 세트의 효과 수치, 일부 무기의 전체 패시브, 인게임 한국어 스킬명의 직접 대조.
- 조건이 완전히 확인되지 않은 DPS·전용 무기 효율·잠재별 피해 그래프.
- 스토리 평점과 국내외 커뮤니티 전체 분위기. 제한된 표본을 점수로 만들지 않았습니다.
- 업데이트 작업 정의는 수집 지침이며 자동 실행 스케줄을 새로 만들지는 않습니다.

## 검증

`tests/endfield.test.ts`에서 데이터 등록, 서버 시간, 서로 다른 마감,
픽업과 버전 종료 구분, 모집 확률 재현, 긴급 모집 집계, 잠재 에너지 계산을 확인합니다.
일반 검증기는 출처 도메인, 이미지 파일, 교차 링크, 길이, 필드와 섹션을 함께 검사합니다.

정상 환경: `npm run validate && npm test && npm run check && npm run build`.
소켓을 열 수 없는 검사 환경에서는 `node --import tsx scripts/validate.ts`,
`node --import tsx --test tests/*.test.ts`, `npm run check`, `astro build`를 각각 실행할 수 있습니다.
